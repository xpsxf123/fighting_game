# 《大江户物语》操作方式调研 → 《大蜀国物语》对齐规范

> 依据：Gamezebo 攻略、官方说明书摘要、App Store 描述、玩家 FAQ  
> 用于 S1+ 交互改造

---

## 1. 原作操作模型（要点）

### 1.1 主画面

| 元素 | 行为 |
|------|------|
| 地图 | **拖拽/触控滚动**平移；支持**双指缩放**（手机） |
| 左下 | 可展开的**方向轮盘**（点箭头展开，再点方向移动镜头）；可收起 |
| 点住民/建筑 | 打开**对象信息**（非直接建造） |
| 秘书对话 | 弹窗，点继续 |

主画面**没有**一排常驻建筑按钮。

### 1.2 菜单（核心）

点 **「菜单 / Menu」** 进入宫格菜单，典型入口：

- **建设 Build** → 再分 **环境 Env / 商店 Shop / 设施 Facilities**
- **研究 Research**
- **住民 People**
- **横丁一览 Combo List**
- **经济 / 旅人**（Economy）
- **地图 Map**（总览，可双击跳转）
- **系统 System**（音效、**角色速度**、画质等）
- **保存 Save**

### 1.3 建造流程（必须一致）

```
菜单 → 建设 → 选分类（环境/商店/设施）
    → 点选某个建筑（显示造价）
    → 自动回到主画面，进入「放置模式」
    → 在地图上点格子放置
    → 可连续点多个格子连造（需小心误触）
    → 取消放置模式（取消/再开菜单）
```

- 环境类含：**道路、拆除锤（锤子图标）** 等  
- 拆除：选锤子 → 点建筑拆除（城除外；原作多数不可直接挪，拆了再建）  
- 放置后有**施工时间**（原作数秒～数分钟）；S1 可缩短为短暂「施工中」

### 1.4 与「我们旧 S1」的差异

| 旧 S1 | 大江户 |
|-------|--------|
| 底栏常驻一排建筑快捷键 | 经菜单选建筑再放置 |
| 底栏直接暂停/速度/存读 | 速度在**系统**；保存在菜单 |
| 无对象点击信息 | 点人/建筑出信息 |
| 无方向轮盘 | 有（可简化保留拖拽+轮盘） |

## 2. 《大蜀国物语》对齐后的操作（S1 实装）

### 2.1 主 HUD

- **顶栏**：金币、声望、年月日周  
- **右下：菜单** 按钮  
- **左下：镜头轮盘**（展开/收起）  
- **放置模式条**：选中建筑名 + 造价 +「取消」  

### 2.2 菜单宫格（S1 子集）

| 按钮 | 作用 |
|------|------|
| 建设 | 进入建设分类 |
| 坊巷 | 宵夜巷说明（S1） |
| 住民 | 列表（简） |
| 系统 | 暂停、1x/2x/3x、说明 |
| 保存 | 存档 |
| 读档 | 读档 |
| 关闭 | 关菜单 |

### 2.3 建设分类

- **环境**：土路、宅基、田、园圃、**拆除**  
- **商店**：面馆、抄手摊、火锅摊  
- **设施**：S1 暂空或仅提示「后续解锁」（园圃已放环境亦可）  

选中后关菜单 → 放置模式。

### 2.4 地图交互

- 拖拽平移（放置模式下短拖仍平移，轻点才建造——阈值阈值）  
- 放置模式：点可建格建造；点拆除锤则拆非路关键建筑  
- 非放置：点建筑/住民 → 底部信息卡  

### 2.5 暂不做（原有但 S1 可后置）

- 双指缩放、研究页、完整旅人经济、总览地图双击跳转  

---

## 3. 验收（操作向）

1. 主界面看不到一排建筑按钮，只有菜单  
2. 能走通：菜单→建设→商店→面馆→回地图连点两格  
3. 菜单→建设→环境→拆除→点掉错误建筑  
4. 系统里能改速度/暂停  
5. 点住民或店铺能看到简单信息
