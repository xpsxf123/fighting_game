## 1. 目标

让单局进入**中期厚度**：工巧发现/制作、客旅来访、全国声望排名、载具扩圈；坊巷与建筑池扩充，支撑 5～8 年不空虚。

---

## 2. 已确认设定（S3 推荐默认）

| 项 | 值 |
|----|-----|
| 工巧失败 | **只耗研策**，无安慰奖；Toast 提示失败 |
| 客旅 | **简化版**：来访条 + 进度条，满额随机奖励（不做复杂追踪列表） |
| 排名 | **假全国档**：由本城声望+年份推算名次（1～99），非实时 AI 城 |
| 载具 | **住民自动购**：到访马厩且钱包≥120 时买驴马（步行+10） |
| 文案 | **中等川味** |
| 坊巷 S3 | 先 **3 条**（宵夜巷保留 + 茶米巷 + 市井巷） |
| 工巧 S3 | **10 种**，货栈 5×5 环境决定发现池 |
| 客旅 S3 | **5 团** |
| 排名奖 S3 | **3 档**解锁建筑（温泉院/擂台/石佛占位） |

---

## 3. 范围 In / Out

### In

1. **工巧**：匠人货栈工作发现；菜单「工巧」查看/制作/使用；升级 Lv1～3  
2. **客栈 + 客旅**：研究解锁客栈；有客栈后客旅来访；满意领奖  
3. **全国排名**：每年 11 月第 4 周结算；顶栏显示名次；达标解锁建筑  
4. **载具**：研究解锁马厩；驴马 +10 步行  
5. **坊巷 ×3**、建筑 **客栈/马厩/温泉/擂台**  
6. **存档 v4**、S3 贴图程序化生成  

### Out（留 S4）

- 工巧 40+ 全表、客旅 12+、白马/马车、坊巷 10～15 条全做、三地图  

---

## 4. 验收清单

1. 匠人多次在货栈工作，能发现 ≥1 种工巧并制作成功  
2. 建造客栈后，客旅来访并完成一次领奖  
3. 玩到第 2 年 11 月可见排名结算，并解锁 ≥1 档排名建筑  
4. 住民在马厩买到驴马，步行圈明显变大  
5. 除宵夜巷外，再成立 ≥1 条坊巷  
6. 存读档 v4 正常  

---

## 5. 数值草案

| 项 | 值 |
|----|-----|
| 客栈 | 180 金；维护 3；年≥2 研策解锁 |
| 马厩 | 150 金；维护 2；年≥3 研策解锁 |
| 驴马 | 住民付 120 金；步行 +10 |
| 工巧制作 | 耗四色研策 3～12；成功率 55%～85%（看手艺） |
| 排名公式 | `rank = clamp(99 - floor(prestige/(60+year*30)), 1, 99)` |
| 排名奖 | ≤60 温泉院 · ≤40 擂台 · ≤20 石佛 |
