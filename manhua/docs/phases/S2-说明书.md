让前中期出现「解锁 → 变强 → 再解锁」：筑衙署州城、住房升级涨税、研策解锁新建筑、有城后可便宜转职。

## 3. 范围 In / Out

### In（做）

1. **州城（衙署）**  
   - 建设·设施可选；造价较高；全图限 1 座  
   - 落成不可拆除  
   - 辐射：曼哈顿 ≤3 的建筑声望加成、年贡地价加成  
2. **住房改建**  
   - 茅棚 → 草屋 → 瓦屋  
   - 税率约 30% → 40% → 50%  
   - 条件：玩家金币 + 该屋住民钱包门槛（可点住房升级）  
3. **四维**  
   - 智略 / 忠勤 / 风仪 / 手艺（初始随机低值）  
   - 进店/园圃仅 **正向** 微调；点人可见  
4. **研策四色**  
   - 食 / 武 / 技 / 学；逛街与园圃掉落  
   - 菜单「研究」：消耗研策解锁建筑（含年份门槛）  
   - S2 至少解锁 3 项：井、茶馆、米铺（示例）  
5. **转职**  
   - 需已有州城  
   - 农/匠/商 → 甲士（费用低）；甲士以上缴/城务为工作点  

### Out（不做）

- 负属性店、工巧、客旅、排名、载具、木楼及以上改建、多州城  

---

## 4. 验收清单

1. 能建造州城；尝试拆除提示不可拆  
2. 州城附近建筑声望/年贡明显高于远处  
3. 至少完成一次 茅→草 或 草→瓦  
4. 住民有四维，进店后可见小幅上升  
5. 研究界面能解锁 ≥3 个新建筑且受年份门槛限制  
6. 有州城后能把一名住民转成甲士并看到其行为变化  
7. 自动存 + 手动存读仍可用  

主观：感到「筑城/升级/研究」在推动变强 → S2 过门。
