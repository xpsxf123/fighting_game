## 4. 验收清单（你过门用）

**手感**

1. 竖屏打开，能暂停 / 1x2x3x  
2. 菜单→建设→环境/店铺→回地图连点放置；能铺路扩可建  
3. 至少 2 个小人在动；选人可见蓝格步行范围  

**逻辑（原 S1b）**

4. 家远离田/货栈 → 住民钱包难涨、飘「工作太远」  
5. 路通 + 工作点可达 → 钱包上涨；建店后有人消费（飘消费，金币不因进店暴涨）  
6. 宵夜巷三件套成立 → Toast + 持续加成（非一次性发钱）  
7. 玩到 **4 月第 4 周** 至少一次年贡到账  
8. 杀进程再进能读档  

主观：**还想再摆一点，且理解「布局=贫富」** → 过门进 S2 问答。

## 5. 玩法提示（自测建议）

1. 开局已有田与货栈：观察农夫去田、匠/商去货栈涨钱包。  
2. 故意把新宅基建在地图远端且不修路 → 迁入后变穷。  
3. 建面馆+抄手+火锅凑≤3 → 看坊巷页与店物价/声望。  
4. 加速到 4-4 看年贡；平时玩家金币主要靠迁入费与年贡，不是进店。
