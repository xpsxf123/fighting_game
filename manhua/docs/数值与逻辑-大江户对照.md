## 1. 原作核心经济因果（必须理解）

```
住民有家、有职业、有钱包、有步行上限
    │
    ├─► 走到「工作点」赚钱进钱包（田 / 货栈 / 城）
    ├─► 走到「商店」消费：店涨级、掉研究点、改四维、店主/经济循环
    ├─► 走到「公园」交际：魅力相关，涨属性/研究
    │
玩家不直接「进店收银」，主要收入来自：
    ├─► 年贡（房屋地租比例 × 相关石高）
    ├─► 总石高带来的排名/解锁/迁入费
    └─► 部分经营相关结算（城、问屋周边等）
```

**已纠正**：小人进店 → 扣住民钱包；玩家主收入靠四月年贡与迁入费。

## 2. 行走逻辑（People’s Movements）

### 2.1 原作规则摘要

1. **只沿道路移动**（路径连通）。  
2. **步行距离上限约 9～14 格**（个体有差异；以家或可达工作点为半径理解）。  
3. 超过距离：到不了田/货栈/城 → **赚不到钱**；常见表现是常去公园、喊没钱。  
4. **马厩买马**：距离 +10；白马 +20；特殊载具近乎无限（后期）。  
5. 马厩本身也必须在步行可达范围内，否则买不到马。  
6. 城可影响远处建筑收益（辐射），但不等于取消步行限制。

### 2.2 目标实装（大蜀国）

| 字段 | 说明 |
|------|------|
| `walkRange` | 基础 9～14，按住民个体随机或随成长微调 |
| `vehicleBonus` | 0 / +10 / +20 / ∞ |
| `maxReach` | `walkRange + vehicleBonus` |
| 寻路 | 沿道路 BFS；目标若路径长度 > maxReach 则不可选 |
| 工作目标 | 按职业优先：农夫→田；匠/商→货栈；有城则周期性「上缴/城务」 |
| 休闲目标 | 商店（消费）、园圃（交际）、家 |

### 2.3 落地状态

- **已做**：`baseWalk`/`walkRange` + 载具（驴+10、白马+20、轿车近乎无上限）；沿路 BFS；超距不可选；钱包穷强制工作、有钱闲逛消费；职业工作点按文档绑定。  
- **简化**：道路等级不单独叠乘（仅个体步行基值）；堵路「唯一通路必工作」未单独建模。

## 3. 住民与职业逻辑

### 3.1 四维（原作）

| 属性 | 作用 |
|------|------|
| 知力 Int | 易发现/研究相关，升级加快 |
| 忠诚 Loy | 工作更卖力 → 产出/贡献↑ |
| 魅力 Apl | 易在公园相遇 → 研究与互相加属性 |
| 才能 Skl | 易发现工巧、制作成功率 |

### 3.2 职业与工作（原作）

| 职业 | 主要工作点 | 备注 |
|------|------------|------|
| 农民 | 田 | 耕作阶段性 |
| 職人 | 货栈 | 可做工巧 |
| 商人 | 货栈 | 消费力强 |
| 武士 | 城/田等 | 高石高贡献 |
| 幕臣 | 顶级 | 稀缺 |

职经验：访问特定建筑获得；不同建筑对不同职业经验不同（有完整表）。

### 3.3 住房改建（原作）

条件≈钱包门槛 + 邻接道路类型 + 职级总和。  
地租占「地价」比例：茅棚 30% → … → 私邸/小城 65%。  
**年贡看房屋等级，不扣钱包。**

## 4. 建筑特征模型（每栋建筑一张卡）

原作每栋建筑至少包含：

| 字段 | 含义 | 示例（うどん屋量级） |
|------|------|----------------------|
| `cost` | 建造费 | 80 两级 |
| `maint` | 维护费 | 2/期 |
| `yield` | 基础石高 | 40 |
| `priceMin~Max` | 商品标价区间 | 6～8 |
| `stats` | 四维修正 | 如 +知 / ++忠 / 0 / 0 |
| `rp` | 四色研究掉落权重 | 食/武/技/学 |
| `jobExp` | 对各职业经验 | 农4 / 匠0 / … |
| `category` | 环境/店/设施 | |

**商店特征**：住人进店 → 店参数↑ → 可能升级；给客人改属性；掉 RP；客人钱包减少。  
**田特征**：农民工作，阶段收成进钱包。  
**货栈特征**：匠/商工作收入；周围 5×5 决定工巧发现池。  
**园圃特征**：交际、涨魅力相关。  
**城特征**：全职相关收入/石高、转职、大范围 yield 加成；**不可拆**。  
**自然**：邻接住宅/店铺加石高；部分参与坊巷「自然」通配。

### 4.1 负属性建筑（原作重要坑）

部分高收益建筑会 **降忠诚/才能等**。  
工巧发现依赖魅力+才能 → 后期要「培养区」与「赚钱区」分离，或拆负属性店。  
**平衡设计必须保留正负修正，不能全加 buff。**

## 5. 坊巷（横丁）精确逻辑

| 规则 | 原作 | 大蜀国目标 |
|------|------|------------|
| 成立范围 | 约 **4×4** 内收齐三件（不必紧贴） | 用「包围盒≤4」或「两两距离≤3」等价 |
| 效果范围 | 以相关建筑为中心 **5×5** 抬石高/物价 | 同 |
| 自然物 | 可作构件；**自然为中心不发射 5×5** | 同 |
| 叠乘 | 可多重叠 | 同 |
| 加成 | 石高% + 商品价值% | 声望/产量% + 店标价% |

S1 现状「触发一次奖金」→ **必须改为持续百分比修正建筑 yield/price**。

## 6. 石高 / 声望 / 金币（术语映射与公式）

| 原作 | 大蜀国文案 | 本质 |
|------|------------|------|
| 両 Gold | 金币 | 现金流 |
| 石高 Yield | 声望（可改回「石高」） | 城评级主指标 |
| 商品价值 Price | 物价 | 影响消费与店表现 |
| 研究P | 研策（食武技学） | 解锁与工巧 |

### 6.1 总石高（示意，可调参）

```
TotalYield = Σ ( BuildingYield_i * (1 + ΣComboYield%) * EnvAdj * CastleAura )
           + Σ ResidentYieldContribution
           + Σ CraftYieldOnUse/Owned
```

### 6.2 年贡（对齐原作结构）

```
Tax = Σ over homes (
  LandPrice(home) * RentRate(houseTier) * f(localYield)
)
结算月：建议每年 4 月（原作 April）；S1 曾用 3 月末可改回 4 月
```

RentRate：30% / 40% / 44% / 48% / 50% / 65% 对应住房链。

### 6.3 玩家不该「进店直接收银」

店消费：  
`wallet -= price`；`shop.param++`；可能 `drop RP`；`apply stat mods`。  
玩家通过年贡、迁入费、总石高成长获利。

## 7. 开局与节奏数值锚点（原作）

| 项 | 原作锚点 | 短局 4～6h 缩放建议 |
|----|----------|---------------------|
| 开局金 | 1500 | 保持 1500（已对齐） |
| 主线年 | ~16 年 3 月 | 可 8～12 年等价，周更快 |
| 冲榜石高 | ~15 万～20 万+ | 目标改为「短局可达的比例尺」，如 3～5 万，但曲线同形 |
| 周 tick | 现实时间较慢 | 可加速，但每周结算内容对齐 |

**原则**：缩时间、缩目标绝对值；**不删**「距离不够就穷」「改建涨税」「坊巷抬 yield%」因果。

## 9. 分阶段落地（写入项目计划）

| 阶段 | 必须完成的逻辑对齐 |
|------|-------------------|
| **S1**（含原 S1b，已做） | 菜单建造、铺路可建、步行上限、职业工作点、钱包、年贡比例、坊巷持续% |
| **S2** | 四维修正表、研策四色、研究解锁、州城辐射与转职、住房改建链 |
| **S3** | 工巧发现 5×5、载具、客旅、完整建筑特征卡填满内容池 |
| **S4** | 全表数值按短局重平衡 + 三地图 |

### S1 逻辑验收（原 S1b）

1. 把家建得远离田/货栈 → 住民明显变穷/少产出  
2. 铺路+工作点可达 → 钱包与年贡上升  
3. 宵夜巷成立后，相关店**持续**更高表现（不是一次性弹奖金）  
4. 年贡按茅棚×地价×税率；更好住房档待 S2 改建链
