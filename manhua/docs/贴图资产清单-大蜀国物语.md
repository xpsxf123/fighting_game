# 《大蜀国物语》贴图资产清单 + 生成提示词

> 用途：后期用 AI / 像素师批量出图  
> 画风统一前缀见 §0  
> 优先级：`P0`=M1 切片必做 · `P1`=首发完整 · `P2`=后期补强  
> 建议规格：逻辑格子 **32×32** 或 **48×48**；建筑可 **32×48 / 64×64**（脚底对齐格子）；导出 PNG 透明底

---

## 0. 全局风格前缀（每条提示词前都加）

### 0.1 英文主前缀（推荐给 Midjourney / SD / Flux）

```text
Kairosoft-like cozy pixel art, isometric 3/4 top-down view, bright saturated colors,
Sichuan / Shu kingdom ancient Chinese town aesthetic, cyan-grey roof tiles, bamboo and wooden buildings,
warm lantern orange accents, clean pixel clusters, 32x32 game sprite style, crisp outlines,
no modern objects, no Japanese torii, no anime face close-up, transparent background, game asset
```

### 0.2 中文主前缀（国产工具可用）

```text
开罗游戏风格的可爱像素画，斜45度俯视，高饱和明亮配色，中国蜀地古代市井，
青瓦竹木建筑，暖黄灯笼点缀，清晰像素块，游戏贴图，干净描边，
不要现代物品，不要鸟居和风，不要大头立绘特写，透明背景，游戏素材
```

### 0.3 负面提示（Negative）

```text
blurry, photo, 3d render, realistic, dark gloomy, cyberpunk, purple neon,
japanese torii, ninja, cherry blossom japan postcard, watermark, text, UI mockup,
lowres, deformed, multiple buildings in one sprite unless requested
```

### 0.4 出图约定

| 类型 | 画布建议 | 备注 |
|------|----------|------|
| 地形/道路 tile | 32×32 无缝或可拼接 | 可出 tileset 大图再切 |
| 单格建筑 | 32×48 或 48×48 | 脚底中心对齐格子 |
| 大建筑（州城等） | 64×64 / 96×96 | 占 2×2 格 |
| 角色 | 16×24 或 24×32 | 需多帧时注明 spritesheet |
| UI 九宫格/面板 | 任意，留边可拉伸 | 与场景像素密度一致 |
| 图标 | 32×32 | 统一圆形或方底 |

## 15. 使用注意

1. 同一批尽量固定 seed / 同角色参考图，避免「每栋楼画风漂移」。  
2. AI 出图后需 **人工裁切对齐脚底锚点**，并统一描边 1px。  
3. 有文字的招牌尽量留空，游戏内用字体叠字，避免 AI 乱码字。  
4. 禁止生成开罗官方角色/开罗君外形；吉祥物用原创熊猫/瑞兽。
