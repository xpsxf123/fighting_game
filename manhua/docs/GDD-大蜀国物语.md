# 《大蜀国物语》游戏设计文档（GDD）

> 版本：v0.1 Draft  
> 对标原作：开罗软体《大江戸タウンズ / Oh! Edo Towns》  
> 辅助方法论：Jesse Schell《The Art of Game Design》透镜（`schell-game-design`）  
> 合规：复用**玩法骨架与节奏**；**不复制**开罗商标、角色名、原版贴图、BGM/音效与原文案。美术与命名全面中国·蜀地本土化原创。

---

## 0. 一句话卖点

你是蜀地一方小城主：铺路招民、摆店组「坊巷」、培养农夫→匠人→商贾→甲士→幕僚，用研究点解锁建筑与工巧，冲全国粮赋排名，把荒村建成「大蜀国」。

## 1. Schell 透镜定锚（先定体验，再定系统）

### 1.1 Problem Statement（Lens #12）

| 项 | 内容 |
|----|------|
| 目标 | 做一款与《大江户物语》**高相似度**的城建经营模拟，舞台换成中国虚构「蜀国」 |
| 约束 | 单人、像素斜俯、无内购压迫；首发 PC/手机；机制对齐原作核心循环；资产 100% 原创 |
| 非目标 | 真三国战争 SLG、开放世界、联机对战、1:1 像素抄图 |

### 1.2 Essential Experience（Lens #1）— 必须保住的感觉

玩家应持续感到：

1. **「我在养一座会呼吸的城」** — 小人走路、进店、种田、聊天，城在「自己长大」  
2. **「摆对三样东西，整条街就发财了」** — 坊巷组合带来的布局爽感  
3. **「年贡来了」** — 每年一次的大回款节奏（紧张→释放）  
4. **「排名涨了」** — 粮赋全国榜带来的长期目标与公平评判感（Lens #20 Judgment）  
5. **「蜀味市井」** — 茶馆、火锅、蜀锦、栈道、都江堰意象，而非江户町屋表皮  

**可砍**：过度写实的三国剧情树、复杂战争。  
**不可砍**：小人自主活动、组合布局、年贡、研究解锁、职业晋升、工巧养成。

### 1.3 主题统一（Lenses #9–10 Unification / Resonance）

- **表层主题**：蜀地城建  
- **体验主题**：「从边陲荒村到天下名城的经营自豪」  
- **共鸣点（Resonance）**：中国玩家对「老家小镇变繁华」「一方水土养一方人」的熟悉感；川蜀饮食与商路文化提供记忆钩子  

所有设施命名、组合名、旅人台词、地图地貌都要服务这一主题，避免日式和风残留。

### 1.4 Elemental Tetrad（Lens #7）

| 象限 | 本项目落点 |
|------|------------|
| Mechanics | 网格城建 + 组合加成 + 住民 AI + 粮赋经济 + 研究/工巧 |
| Aesthetics | 明亮像素、蜀地青瓦竹木、暖黄灯笼、青绿山水点缀 |
| Story | 轻叙事：小吏助手带路 + 报纸事件 + 旅人轶事（Story Machine） |
| Technology | 2D 格子地图、轻量 agent 寻路、表驱动配置 |

### 1.5 六大机制骨架（Lens #21–29）

| Schell 六机制 | 《大江户》原作 | 《大蜀国物语》对齐 |
|---------------|----------------|-------------------|
| Functional Space | 离散格子地图；移动半径受交通工具限制 | 同：格子城建；步行/驴/白马/轿子扩半径 |
| Objects/State | 建筑等级、住民四维、钱包、粮赋 | 同结构，改名改皮 |
| Actions | 建造、拆除、研究、转职、制作工巧、使用工巧 | 同动词集（少而深，利 Emergence） |
| Rules/Goals | 16 年冲全国粮赋榜；可续玩 | 同：主目标 15–16 年内冲榜；可续玩 |
| Skill | 布局规划、资源分配、职业配比 | 同：心智技能主导 |
| Chance | 工巧发现、旅人、商店掉研究点 | 同：用 EV 保证「值得赌」而非无助 |

## 2. 原作机制深挖（对齐清单）

### 2.1 核心循环

```
铺空地招民 → 建田/店/设施 → 住民走动消费升级店铺
→ 掉研究点 → 研究新建筑 → 组成坊巷（横丁）抬粮赋/物价
→ 每年征税 → 全国粮赋排名解锁大奖建筑
→ 筑城转职 → 工巧发现与使用 → 旅人满意给奖
→ 扩交通工具扩大活动半径 → 冲榜
```

### 2.2 原作关键术语对照

| 原作（日/英） | 本项目（蜀） |
|---------------|--------------|
| 石高 / Yield | **粮赋**（显示单位：石） |
| 横丁 / Combo | **坊巷** |
| 研究ポイント | **研策点**（食/武/技/学 四色） |
| 工芸品 / Craft | **工巧** |
| 商品問屋 / Wholesaler | **货栈** |
| 空地 / Vacant Lot | **宅基** |
| 城 / Castle | **州城**（不可拆除，落点永久） |
| 旅人 / Traveler | **客旅** |
| 両 / Gold | **贯**（货币） |
| 農民/職人/商人/武士/幕臣 | **农夫/匠人/商贾/甲士/幕僚** |

### 2.3 必须复刻的硬规则

1. **格子建造**：建筑占格；道路扩展可建造域  
2. **建筑不可随意挪**（拆除重建）；**州城一旦建成不可拆**  
3. **坊巷**：指定 3 建筑彼此距离 ≤3 格；可叠加；同建筑可参与多坊巷  
4. **坊巷影响范围**：以相关建筑为中心约 5×5（自然景物单独不触发范围的规则对齐原作）  
5. **住民四维**：智略 / 忠勤 / 风仪 / 手艺  
6. **四色研策**：食、武、技、学 — 逛街、交谈、制作、研究时掉落  
7. **职业五阶** + 城堡后可转职  
8. **房屋改建链**：茅棚→草屋→瓦屋→木楼→大宅→私邸…（钱包+职业等级条件）  
9. **每年固定评粮赋排名**（约 11 月某周）→ 首次达标解锁特殊建筑  
10. **货栈周围 5×5** 决定可发现的工巧种类  
11. **客栈** 吸引客旅；满意后给奖励，仍可继续来  
12. **交通工具** 扩大移动半径（驴→白马→轿子/车）  
13. **主线约至第 16 年三月**可结算；可续玩；二周目可继承部分解锁

## 3. 产品设定（中国·蜀版）

### 3.1 基础信息

| 项 | 内容 |
|----|------|
| 中文名 | 《大蜀国物语》 |
| 英文名 | *Grand Shu Towns* |
| 类型 | 城建经营模拟 / 像素 |
| 时代 | 虚构「大蜀」承平年代（服饰偏汉唐+川蜀市井，不严格考据） |
| 助手 NPC | **小吏「青荷」**（对应原作引导秘书） |
| 开局资金 | 1500 贯 |
| 存档 | 2 槽；重要操作后建议存盘 |

### 3.2 开局地图三选一（对齐原作）

| 地图 | 气质 | 玩法倾向 |
|------|------|----------|
| **平畴乡** | 平均平原 | 教学友好、均衡 |
| **剑门谷** | 山地多、可建地碎 | 挑战布局，后期风景加成 |
| **锦江浦** | 水岸多 | 渔市/码头向组合强 |

### 3.3 城镇等级名（对齐 Village→Town→City→Province→Oh! Edo）

`荒村 → 乡聚 → 县镇 → 州府 → 锦城 → 大蜀`

等级由：住民数、建筑数、粮赋总量、坊巷数等综合推进，解锁研究目录与设施。

## 4. 界面与信息架构

### 4.1 主画面

```
┌─────────────────────────────────────────────┐
│ 顶栏：城名 | 贯 | 粮赋 | 研策(四色) | 年月日周   │
├──────────────────────┬──────────────────────┤
│                      │ 点选信息卡             │
│  斜45°格子城镇视图    │ 建筑/住民/坊巷提示      │
│  小人走动 + 头顶冒泡   │                       │
├──────────────────────┴──────────────────────┤
│ 底栏：建造 | 研究 | 住民 | 经济 | 坊巷一览 | 菜单 │
└─────────────────────────────────────────────┘
```

### 4.2 操作手感（Lens #53–60 Interface）

- 点击建筑/人打开卡片；建造模式「幽灵预览 + 坊巷高亮」  
- 地图总览色块：路/店/田/宅/自然  
- 时间流速 1x/2x/3x  
- **果汁反馈**：组成坊巷时金色「坊巷成立！」字跳 + 鼓点；年贡时银两雨  

### 4.3 间接控制（Lens #71–73）

不强迫布局，但通过：

- 助手提示「茶馆旁宜放蜀锦铺」  
- 坊巷列表展示未完成差一建筑  
- 州城辐射光圈暗示「围着城建更赚」  

让玩家感觉「自己想出来的」，实则被引导。

## 5. 时间与经济节奏

### 5.1 时间

- 年 / 月 / 周；周为 tick  
- 游戏内主要结算按周推进小人行为  

### 5.2 年度节奏

| 时间 | 事件 |
|------|------|
| 每年约 3–4 月 | **年贡入库**（按房屋与粮赋；不扣住民钱包） |
| 每年约 11 月某周 | **全国粮赋排名**结算与解锁 |
| 随机 | 朝廷赏赐/赈济（低资金救济）、报纸八卦 |
| 条件触发 | 可筑新城、客旅到访、工巧发现提示 |

### 5.3 资金三角性（Lens #31 Triangularity）

| 选择 | 风险 | 回报 |
|------|------|------|
| 猛铺宅基招人 | 维护费上涨、前期穷 | 年贡与客流长期高 |
| 攒钱筑城 | 短期发展慢 | 转职与税收质变 |
| 砸研策赌工巧 | 可能失败 | 粮赋跳涨 |

保持三种路线 EV 接近但手感不同。

## 6. 空间与建造

### 6.1 地块规则

- 仅陆地可建；道路扩展建造边界  
- 道路类型：土路 / 木板路 / 石板路 / 青砖路（影响改建与邻接加成）  
- 拆除：环境菜单锤子工具；多数建筑拆后需重买  
- **州城：落成后永久固定，最多 3 座**（条件逐步解锁）

### 6.2 建筑三大类

1. **环境**：路、宅基、田、货栈、仓、井、竹林、芙蓉、梅、池、稻草人…  
2. **商店**：消费涨店等级与物价区间；改住民四维（+/-）  
3. **设施**：州城、园圃（公园）、客栈、书院、武馆、官衙…  

> 解锁计数时：环境多数不计「建筑数」；州城/园圃/客栈不计 — 对齐原作。

### 6.3 田与货栈

- **稻田/菜田**：农夫耕作阶段性产出，粮赋高则收入高  
- **货栈**：匠人/商贾主要收入点；周围 5×5 决定工巧发现池  
- **大货栈**：后期扩容版  

### 6.4 宅基与住房链

| 住房 | 地租（占地价%） | 改建条件（示意） |
|------|-----------------|------------------|
| 茅棚 | 30% | 初始 |
| 草屋 | 40% | 钱包 ≥25 |
| 瓦屋 | 44% | 钱包≥35 且 职级≥3 |
| 木楼 | 48% | 钱包≥50 且 职级≥4 且 总职级≥6 |
| 大宅 | 50% | 钱包≥54 + 青砖路邻接 + 总职级≥13 |
| 私邸 | 65% | 钱包≥70 + 石板路 + 总职级≥25 |

改建消耗「看起来」要有钱，但不一定真扣钱包（对齐原作手感，可用伪条件触发）。

## 7. 住民系统

### 7.1 四维

| 属性 | 作用 |
|------|------|
| **智略 Int** | 易发现新设施倾向、升级加快 |
| **忠勤 Loy** | 工作更卖力 → 贡献粮赋/产出↑ |
| **风仪 Apl** | 易在园圃与人相遇 → 研策与互相加属性 |
| **手艺 Skl** | 易发现工巧、制作成功率↑ |

商店/设施访问时对四维有 +/-（部分店降属性 — 玩家需规划「培养区」与「赚钱区」）。

### 7.2 职业

| 职业 | 解锁 | 定位 |
|------|------|------|
| 农夫 | 初始 | 耕田 |
| 匠人 | 匠人迁入后 | 制作工巧 |
| 商贾 | 商贾迁入后 | 消费力强、经济 |
| 甲士 | 农/匠/商均达 Lv4–5 | 高粮赋/高研策 |
| 幕僚 | 甲士 Lv5 + 其余满 | 稀缺顶级 |

- 职级 1–5；访问建筑获职经验（不同建筑对不同职经验不同）  
- **有州城后**可付费转职  
- 每掌握一个满级职业，额外被动经验（对齐原作）  

### 7.3 移动半径与交通

| 载具 | 半径加成 | 获得 |
|------|----------|------|
| 步行 | 基础 9–14 | 默认 |
| 驴马 | +10 | 任意住民于马厩购买 |
| 白马 | +20 | 甲士 Lv4+ 且钱包够，马厩概率 |
| 轿车/马车 | 近乎全图 | 幕僚 Lv5 +「番货坊巷」影响下的马厩 |

→ 布局必须考虑「早期小人走不远」——这是核心空间谜题。

### 7.4 钱包

住民逛街花钱→店升级；钱包影响改建与买马；年贡不扣钱包。

## 9. 研究与解锁

### 9.1 研策四点

住民头顶冒泡积累：

- 食（红）/ 武（橙）/ 技（蓝）/ 学（紫）  

来源：购物、交谈、制作、主动研究行为。

### 9.2 研究建筑

菜单「研究」→ 消耗对应研策 + 时间 → 解锁可建造条目。  
城镇等级与粮赋门槛控制研究目录深度。

### 9.3 粮赋排名奖（示意，对齐原作档）

每年排名首次达标解锁（已有则随机重复奖池）：

| 排名门槛 | 奖励建筑（蜀名） |
|----------|------------------|
| ≥74 | 大石佛 |
| ≥64 | 州衙 |
| ≥57 | 六层塔 |
| ≥42 | 温泉院 |
| ≥28/16 | 相扑→改为 **擂台/川剧亮相台** |
| =1 | 吉祥雕像（终局彩蛋建筑） |

## 10. 工巧系统（原作工芸品）

### 10.1 发现

- 匠人进入 **货栈** 时概率发现新工巧  
- 种类由货栈周围 5×5 内建筑决定  
- 高风仪+高手艺提高发现/制作成功率  
- 制作主要耗研策（可不耗金）— 穷期抬粮赋神器  

### 10.2 使用

- 可对 **住民** 或 **建筑** 使用

## 11. 州城与税收

### 11.1 筑城条件（示意）

满足其一可+1 城上限（最多 3）：

- 有商贾 + 总粮赋达标 + 年份  
- 或全国排名达标档  

### 11.2 州城功能

- 全职业相关税收/粮赋结算中枢  
- 周围大范围建筑粮赋加成  
- **解锁转职**  
- 影响远距建筑收益  

**落点策略**：尽量居中、靠近商业集群 — 助手必须强提醒「不可后悔」。

## 13. 商店/设施对属性与研策的设计原则

每店配置：

- 造价 / 维护 / 基础粮赋 / 物价区间  
- 四维修正（++/+ /0 /- /--）  
- 四色研策掉落权重  
- 对各职业的访问经验  

**平衡要点（原作坑点要保留为策略）**：

- 部分高收益店会降忠勤/手艺 → 需要「培养园区」与「氪金商业区」分离

## 17. 数据与公式（设计版）

### 17.1 单建筑有效粮赋（示意）

```
Yield_eff = Yield_base 
          * (1 + ΣCombo_yield%) 
          * (1 + NearbyEnvBonus) 
          * (1 + CastleAura) 
          * CraftMods
```

### 17.2 年贡（示意）

```
Tax = Σ( HouseRentFactor * LocalLandPrice * JobYieldWeight )
```

### 17.3 工巧成功期望（EV）

```
P_success = f(Skl, Apl, CraftLevel, WholesalerContext)
EV = P_success * YieldGain - ResearchCost_opportunity
```

调参目标：50% 成功率仍值得在中后期频繁尝试（原作玩家行为）。
