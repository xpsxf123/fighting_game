# 《大蜀国物语》dashu-town

竖屏蜀地城建经营（对齐开罗《大江户》骨架）。当前进度：**S5 表现打磨中**（S0～S4 已过门）。

## 怎么玩

### 浏览器

```bash
cd dashu-town
npx --yes serve -p 5173
```

或直接打开 `index.html`（建议 Ctrl+F5 强刷）。

### 微信开发者工具

导入本目录为**小游戏**，AppID 可用测试号。

## 操作

| 操作 | 说明 |
|------|------|
| 拖地图 | 按住滑动平移 |
| **右上「菜单」** | 在**地图画面内**右上角（非顶栏） |
| 顶栏变速区 | 点击暂停 / 1x→2x→3x |
| **右下「返回/关闭」** | 子页返回；主菜单关闭；详情弹窗关闭 |
| **左下「说明」** | 有选中项时出现，查看详情 |
| **放置** | 建设弹窗顶栏切环境/商店/设施 → 点一次选中 → 再点进入放置；地图点格标记后再点蓝格确认 |
| 研究/工巧 | 点一次选中，再点一次确认研究/制作/使用 |
| 住民 | 点一次选中；转职点右侧按钮；再点选中项无反应 |
| 系统 | 暂停、变速、音效、重看教程、三地图新局、继承、存读档 |

年贡：**每年 4 月第 4 周**（报纸面板）。  
全国排名：**每年 11 月第 4 周**（公报面板）。  
首局会弹出**青荷教程**（可跳过；系统可重看）。
